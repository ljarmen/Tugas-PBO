# Array Riko - Program Perpustakaan Sederhana

## Deskripsi

Program perpustakaan sederhana berbasis console menggunakan Java dengan konsep OOP dan Array. Program ini memungkinkan pengguna untuk mendaftar sebagai anggota, melihat daftar buku, meminjam buku, mengembalikan buku, dan melihat daftar buku yang sedang dipinjam.

## Struktur Class

- **Book.java** - Class untuk merepresentasikan buku dengan atribut judul dan status peminjaman.
- **Member.java** - Class untuk merepresentasikan anggota perpustakaan dengan array buku yang dipinjam.
- **Library.java** - Class untuk mengelola array buku dan array anggota perpustakaan.
- **Main.java** - Class utama yang berisi menu interaktif untuk menjalankan program.

## Fitur Program

Saat program dimulai, pengguna diminta memasukkan nama depan dan nama belakang untuk mendaftar sebagai anggota perpustakaan.

Setelah terdaftar, program menampilkan menu utama:

1. Lihat Daftar Buku
2. Pinjam Buku
3. Kembalikan Buku
4. Lihat Buku Dipinjam
0. Keluar
